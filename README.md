# 🚀 EduNexa – Smart Communication Platform for Universities

EduNexa is a university-exclusive communication platform designed to streamline information flow between students, faculty, and administration. From the Vice-Chancellor to individual students, everyone can share announcements, media, documents, and updates — all within a controlled, role-based access system.

---

## 🎯 Key Highlights
Replaces cluttered WhatsApp groups with a centralized, university-branded solution.

Reduces WhatsApp usage by 30% for official academic communication.

Ensures privacy, hierarchy, and clarity in message delivery.

Intuitive UI/UX built for students and staff at all technical levels.

---

## 🧠 Core Features
🔐 Role-based sharing: VC, HODs, faculty, and students can communicate based on access level.

🗂️ Structured information flow: From circulars and assignments to media files and lecture videos.

📥 Multi-format support: Share PDFs, videos, images, and documents seamlessly.

📨 Instant notifications for urgent updates and class-level announcements.

## 🔥 Firebase setup

The app uses Firebase (Storage, Auth and the database). The project's own `app/google-services.json` is not in the repository. To run the app:

1. Create a Firebase project and add an Android app with the package name `com.edunexa`.
2. Download its `google-services.json` and put it in `app/`. It is git-ignored, so it will not be committed.
3. `app/google-services.json.example` shows the expected shape.
4. In Google Cloud Console, restrict the Android API key to the package `com.edunexa` and your signing certificate, and keep your Storage and Database rules closed to signed-in users only.
